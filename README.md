# globe-retail-sales-analysis
Analyzed global retail sales data using Excel and Power Query

## Project Overview
This project focuses on analyzing globe retail sales data to uncover meaningful business insights using Excel and Power Query. The goal is to clean, transform, and analyze raw sales data to understand business performance, customer behavior, and product trends.

## Business Scenario
A globe retail company wants to analyze its sales data across different regions and product categories to improve decision-making. The business requires a structured and cleaned dataset along with summarized insights to understand sales performance, identify top-performing products, and track regional trends.

## Objectives
- Clean and transform raw sales data using Power Query  
- Analyze sales performance across regions and categories  
- Identify top-selling products and revenue contributors  
- Understand customer purchase patterns  
- Create summarized reports for business decision-making  

## Tools Used
- Microsoft Excel  
- Power Query  

## Project Workflow
1. Data Import into Excel  
2. Data Cleaning using Power Query  
3. Data Transformation and Formatting  
4. Creating Pivot Tables and Pivot Charts for Analysis  
5. Building Summary Reports  
6. Extracting Business Insights


## Key Insights
- Identified top-performing regions and products  
- Observed sales trends across different categories  
- Improved data quality through structured cleaning process  
- Generated clear and actionable business summaries  

## Conclusion
This project demonstrates how raw retail data can be transformed into meaningful business insights using Excel and Power Query, focusing on data cleaning, transformation, and basic analytical reporting.
